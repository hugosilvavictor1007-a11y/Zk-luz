# 💡 ZK Luz — Iluminação Sustentável

## 📌 Sobre o projeto

A **ZK Luz** é uma empresa fictícia criada para um projeto escolar de Inovação Tecnológica e Empreendedorismo.

O projeto apresenta uma proposta de **lâmpada recarregável**, desenvolvida com a ideia de unir praticidade, economia e sustentabilidade.

A proposta busca incentivar o consumo consciente e apresentar uma alternativa de iluminação que possa ser reutilizada após o carregamento.

---

## 🌱 Nossa solução

A ZK Luz apresenta uma lâmpada recarregável com foco em:

- 🔋 Reutilização após o carregamento;
- 💰 Economia;
- ♻️ Sustentabilidade;
- 💡 Praticidade;
- 🌎 Consumo mais consciente.

A duração de até 3 meses apresentada no site é uma **estimativa utilizada na proposta acadêmica**, podendo variar conforme a utilização.

## 🎯 Objetivo

O objetivo do projeto é desenvolver um site institucional acessível para apresentar uma empresa sustentável e sua solução tecnológica.

O site busca demonstrar conceitos de:

- Desenvolvimento Web;
- HTML semântico;
- CSS responsivo;
- JavaScript;
- Acessibilidade;
- Empreendedorismo;
- Sustentabilidade.

---

## ♿ Acessibilidade

O projeto foi desenvolvido considerando boas práticas de acessibilidade, incluindo:

- Estrutura HTML semântica;
- Campos de formulário com `<label>`;
- Navegação por teclado;
- Indicadores visíveis de foco;
- Contraste adequado entre texto e fundo;
- Botões acessíveis;
- Menu responsivo;
- Textos descritivos;
- Uso de atributos ARIA quando necessário.
